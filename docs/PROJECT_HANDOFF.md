Sangitam is a Windows-first Java 21 Swing music player. Read [AGENTS.md](../AGENTS.md) for project rules, [README.md](../README.md) for everyday use, and [ARCHITECTURE.md](ARCHITECTURE.md) for package boundaries. This handoff records recent implementation, verification, and open work.

## Current baseline

- Local import and rescan index files in place. The drive chooser accepts absolute paths, and unavailable files keep their catalog references. General and Locations display paged results backed by catalog snapshots. Search reads bounded pages from SQLite. User edits to library metadata survive rescans, and the file-detail restore action can release selected overrides. [Library presentation paging](LIBRARY_PRESENTATION_PAGING.md) · [Home and metadata restoration](HOME_AND_METADATA_RESTORE.md)
- The player uses VLCJ with an external libVLC installation and falls back to JavaFX Media. Local transport, the default Space shortcut, EQ, spectrum, and the optional Windows system media helper are implemented. Native format coverage and system media integration still need interactive verification. [Playbar, artists and shortcuts](PLAYBAR_ARTISTS_AND_SHORTCUTS.md)
- Regular and smart playlists, virtual folders, artist profiles, session journeys and local listening insights are available. Artist profiles can use cached online enrichment. Track metadata comes from local tags, file and folder hints, user edits, and reviewed MusicBrainz matches. Audio analysis supports mood journeys. [Smart playlists](SMART_PLAYLISTS.md) · [Artist enrichment and mood sessions](ARTIST_ENRICHMENT_AND_MOOD_SESSIONS.md)
- Tracks are currently identified by normalized absolute file paths. Playlists, likes, pins, taste and listening history use those paths. Moving media within a managed library will require a durable ID or a complete path remapping strategy before the app can preserve those relationships.

From the repository root, use JDK 21 or newer with `jpackage` on PATH to build and open the portable Windows image. It includes Java and the optional media helper. Keep the image folder together.

```powershell
$launcher = .\package-windows.ps1
& $launcher
```

For development, `.\build.bat` cleans and compiles, and `.\run.bat` opens the compiled app through Maven. A previous build stopped during cleanup because Maven could not delete an obsolete executable under `target\windows`. The specific cause of the delete failure was unconfirmed. Current packaging writes to `dist\windows` and compiles without that clean step. Use `--data-dir <directory>` for isolated runtime checks. The normal catalog lives in the application data directory.

The 100,000-file test shortcut uses its own indexed WAV catalog and reports first paint, workspace readiness, catalog load, and first page separately. The sub-500 ms first-paint target and responsiveness during a fresh full-scale import still need desktop measurement. [Windows launcher and scale test](WINDOWS_LAUNCH_AND_SCALE_TEST.md)
